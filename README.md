# VeriDegree — Soulbound Academic Diplomas

VeriDegree is a decentralized application (DApp) for issuing university diplomas as **Soulbound Tokens (SBTs)**. Diplomas (PDFs and metadata) are hosted on **IPFS** via Kubo, ensuring data integrity.

---

## 🚀 Quick Start Guide

### 1. Run the Stack (Docker - Recommended)

To launch the complete infrastructure (IPFS node, Besu blockchain, and Frontend) with a single command, run this from the root directory:

```bash
docker-compose up -d --build
```

- **Frontend**: Available at **[http://localhost:3000](http://localhost:3000)**.
- **Besu RPC (Node 1)**: Available at `http://localhost:8545`.
- **IPFS (Kubo)**: Available at `http://localhost:5001` (CORS is automatically configured for the frontend).

Alternatively, you can run components manually (see [Manual Local Run](#manual-local-run) below).

---

### 2. Smart Contracts (Foundry)

With the Docker stack running, deploy the Soulbound contract:

```bash
cd contracts
forge script script/Deploy.s.sol --rpc-url http://localhost:8545 --broadcast --private-key 8f2a55949038a9610f50fb23b5883af3b4ecb3c3bb792cbcefbd1542c692be63 --legacy
```

*Note: The private key above is a default dev key for the Besu network.*

---

### 3. Administration (Role Management)

> [!NOTE]
> Even if you run the application via Docker, all smart contract interaction commands (`forge script` and `cast send` below) are executed from your **local terminal (host machine)**. The Besu nodes are exposed on port `8545` of your localhost.

The platform supports two profiles based on smart contract roles:
- **Minter (Admin)**: Authorized to issue/mint new diplomas. Requires the `MINTER_ROLE`.
- **Non-Minter (Student)**: Can view their own diplomas but cannot issue them. This is the default profile for any new wallet.

#### Minter Setup (Admin)

To authorize a wallet to issue diplomas:

1. **Create a Wallet**: Generate a new wallet using `cast` (or use an existing MetaMask account):
   ```bash
   cast wallet new
   ```
   *Note: Safely store the private key so you can import it into MetaMask.*

2. **Import into MetaMask**: Add the private key as an account in MetaMask.

3. **Grant the Role**: Use the default administrator account (the one that deployed the contract) to grant the `MINTER_ROLE`:
   ```bash
   cast send <CONTRACT_ADDRESS> "grantRole(bytes32,address)" 0x9f2df0fed2c77648de5860a4cc508cd0818c85b8b8a1ab4ceeef8d981c8956a6 <NEW_USER_ADDRESS> --rpc-url http://localhost:8545 --private-key 8f2a55949038a9610f50fb23b5883af3b4ecb3c3bb792cbcefbd1542c692be63
   ```
   *Note: The private key `8f2a5...` is the default admin private key.*

#### Non-Minter Setup (Student)

Any account that connects to the DApp **without** the `MINTER_ROLE` is automatically treated as a Student.
1. Simply connect to MetaMask and switch to any other account that hasn't been granted the minter role.
2. The DApp will show the Student Portal showing the diplomas that have been issued to that specific address.

---

### 4. Configuration

1. **Configure**: Open `frontend/src/config/contract.ts` and update `CONTRACT_ADDRESS` with the address generated by the deployment script in Step 2.
2. **Access**: Open **[http://localhost:3000](http://localhost:3000)** (if running via Docker, Next.js will automatically reflect changes).

### 🔍 Manual Local Run

If you prefer to run services manually for development:

#### IPFS (Kubo)
```bash
ipfs config --json API.HTTPHeaders.Access-Control-Allow-Origin '["http://localhost:3000"]'
ipfs config --json API.HTTPHeaders.Access-Control-Allow-Methods '["PUT", "POST", "GET"]'
ipfs daemon
```

#### Besu Network
```bash
cd besu-qbft
docker-compose up -d
```

#### Frontend
```bash
cd frontend
npm install
npm run dev
```
